Rule of Thirds: Version History

New to the extension? See the Guide for how to use it. Prefer to jump straight in? Use Options to make it your own.

UNRELEASED

New Features

Customise Grid

Individual grid lines and intersection circles can now be shown or hidden. Use the new "Customise" section on the Options page.

A circle can be hidden independently of the lines it sits on, for a crossing point with no dot on top of it.

Customise controls should be fully accessible. Comment via review if not.

Live Preview

The Customise section shows two views side by side: a "Hide / Show" map for clicking lines and circles on or off, and a "Preview" showing exactly what the real overlay will look like, using the actual configured colours, opacity and style.

Preview can optionally show a background photo behind the grid, tinted to contrast with the configured colours, for a better sense of how the overlay will sit on a real image. Turn it off via the "Use background photo" checkbox if you'd rather not.

Circle Style

The intersection circles can now be drawn filled instead of as outlines, via the new Outline/Filled option on the Options page. Outline remains the default.

Embedded Frames

A new "Embedded Frames" option applies the grid inside same-origin iframes on a page too, not just the top-level page. Off by default, since iframes are often adverts or other embedded content you probably don't want a grid drawn over.

Unlike the other options, this one only takes effect the next time you toggle the grid on - not on a tab where it's already active.

Toolbar Icon

The extension's toolbar icon now shows a greyscale version when the grid isn't currently active on the page, and switches to full colour as soon as it's turned on.

Since the grid always starts off on a freshly loaded page, the icon resets to greyscale on navigation too.

Colour Picker

Line and circle colour are now chosen with the browser's own colour picker, giving access to the full colour spectrum instead of a fixed set of 8.

The original 8 colours remain one click away via a new Quick Pick row next to each picker.

Both colours also gained an opacity slider, for translucent grid lines and circles.

Grid Dimensions

Grid rows and columns can now be set to 1, effectively removing dividing lines in one orientation instead of always requiring a full grid.

Rows and columns can't both be set to 1 at the same time, since that would draw no lines at all.

Minimum Image Size

The minimum image size the grid applies to - previously a fixed 100x50 pixels - is now configurable from the Options page, along with whether that minimum can apply with width and height swapped, so a tall portrait photo can qualify via its height.

Technical Changes

The default line colour is now white. After reviewing a lot of images, white tends to stand out on significantly more of them than black does - it can always be changed back via the Options page.

Replaced the Materialize CSS/JS library with a small hand-rolled stylesheet, removing a third-party dependency.

Prevented use of the number spinners (eg for circle radius) from filling the page with "Options saved." notifications.

Saved options are now re-validated whenever they're read, guarding against invalid values left behind by older versions of the extension.

Grid and Circles now sit side by side on the Options page rather than stacked, so more of the page fits on screen without scrolling.

When the grid can't be added to a page (eg a restricted chrome:// page), the toolbar icon now shows a brief warning badge instead of failing silently.

Line Colour now has its own section on the Options page, instead of living inside the Grid section.

Fixed the grid not being added to images whose own CSS position is fixed (eg some lightbox/modal patterns) - previously skipped entirely.

Removed a redundant network request that used to happen every time the grid was applied to an image, just to double-check its size.

Grid rows and columns are now capped at 9, avoiding excessively large grids.

A failed save (eg from exceeding the sync storage limit) is now reported, instead of showing a false "Options saved." message.

Line and circle colour values loaded from storage are now sanitized, guarding against corrupted or invalid colours left behind by older versions or manual edits.

Fields belonging to a disabled section (eg Circle Radius when Circles is off) are now visibly greyed out.

"Restore Defaults" now applies immediately with an Undo action, instead of asking for confirmation first.

The toolbar icon's tooltip now describes what clicking it actually does.

v1.7 - 24 May 2024

New Features

Options Page

Added a new Options page allowing control over whether to render grid and/or circles, grid dimensions (see next section), colours and circle radius.

Options are accessed by right-clicking on the extension's icon and selecting Options.

Any changes take effect immediately.

Options are persisted across sessions and will apply to all user's synced browsers.

Grid Dimensions

Extension now allows grids of arbitrary sizes to be rendered. Use the new Options page to control this.

NOTE: Grid size is NOT restricted. Setting grid size to a large number WILL cause performance issues.

Local Images

Extension should now correctly overlay grid for local images opened in the browser.

ie images loaded via file:// protocol)

Technical Changes

Extension no longer has automatic access to every page (it never did anything unless clicked)

Instead, the extension is now only granted access as and when the extension's icon is clicked.
