Embedded Frames

Off by default: embedded frames are often adverts, comment widgets or other content you probably don't want an overlay drawn over. Turn this on only if you specifically need images inside frames covered too.

Takes effect the next time you toggle the overlay on a page - changing it won't take immediate effect as per other options.

Minimum Image Size

Images smaller than this are skipped - tiny icons, hidden elements and decorative spacers are never worth an overlay.

On by default: an image only needs to meet the two sizes in either arrangement, so a tall portrait photo can qualify using its height for the width minimum and vice versa. Turn this off to require the sizes exactly as given.
