Rule of Thirds: Guide

See what's changed recently on the Version History page.

What It Does

Rule of Thirds draws a configurable composition overlay over the images on a page, to help judge composition - a classic grid, a fixed Phi Grid, or a Fibonacci Spiral.

Using the Overlay

Click the toolbar icon to add the overlay to every eligible image on the current page. Click it again to remove it. The icon itself shows whether the overlay is currently on for that tab: full colour when it's active, greyscale when it isn't.

The overlay only applies to images that are actually visible on the page and meet a configurable minimum size (100x50 pixels by default) - tiny icons, hidden elements and decorative spacers are skipped automatically. See Minimum Image Size below to change this.

If a page doesn't allow the overlay to be added at all (eg a restricted chrome:// page), the toolbar icon briefly shows a warning badge instead.

Choosing an Overlay Style

Right-click the toolbar icon and choose Options. The large Composition Overlay toggle at the top picks one of three styles - only one applies at a time, though all three keep their own settings when you switch between them, so nothing is lost by trying another.

Grid - the classic rule-of-thirds grid, with a fully configurable number of rows and columns.

Phi Grid - a fixed 3x3 grid spaced by a ratio (1 : 0.618 : 1 by default) instead of equal thirds.

Fibonacci Spiral - a spiral overlay instead of straight lines.

Customising Grid and Phi Grid

Changes apply immediately to any page the overlay is currently active on.

Grid - turn grid lines on or off, and set the number of rows and columns (1 or more; rows and columns can't both be set to 1, since that would draw no lines at all).

Phi Grid - turn its lines on or off, same as Grid, and edit the Ratio (outer : middle : outer) that spaces them. The same ratio applies in both directions. "Restore Default Ratio" resets just this ratio back to 1 : 0.618 : 1, leaving every other option (including whether Phi Grid itself is enabled) untouched.

Circles - shared by both Grid and Phi Grid: turn intersection circles on or off, set their radius, and draw them outlined or filled.

Line Colour and Circle Colour each have their own colour picker (with a Quick Pick row of common colours one click away) and an opacity slider, for anything from a bold solid line to a barely-there translucent one.

Embedded Frames controls whether the overlay also applies inside embedded frames (iframes) on a page - off by default, since these are often adverts or other embedded content you probably don't want an overlay drawn over. Unlike the settings above, this one doesn't apply immediately: it takes effect the next time you toggle the overlay on a page, not on a tab where the overlay is already active.

Minimum Image Size, at the bottom of the page, sets the smallest image the overlay will apply to (100x50 pixels by default) - tiny icons, hidden elements and decorative spacers stay skipped regardless of how you set this. Either orientation, on by default, lets an image qualify with the width and height minimums swapped too, so a tall portrait photo can use its height to meet the width minimum. Turn it off to require minimum sizes exactly as given.

Fibonacci Spiral

Choose a direction (clockwise or counter-clockwise) and a starting corner - the eight thumbnails show every combination and stay in sync with whichever you pick, in either direction: click a thumbnail to select it, or the radios to highlight the matching thumbnail. The spiral is drawn using Line Colour above.

Hiding Individual Lines and Circles

The Options page's Customise section - shared by Grid and Phi Grid - shows two views side by side: a "Hide / Show" map for clicking individual lines and circles on or off, and a "Preview" showing exactly what the real overlay will look like with your current colours, opacity and style. A circle can be hidden independently of the lines it sits on, for a crossing point with no dot on top of it.

The "Hide / Show" map can be operated entirely from the keyboard: tab to it, then use the arrow keys to move between lines and circles and press Enter or Space to show or hide whichever one is currently selected. A status message for screen readers announces what's selected and whether it's currently shown or hidden.

Preview can optionally show a background photo behind the grid, tinted to match your configured colours, for a better sense of how the overlay will sit on a real image - turn it off via the "Use background photo" checkbox if you'd rather not.
